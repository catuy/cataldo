# Diego Cataldo Portfolio - Project Context

## Overview
Personal portfolio website built with Jekyll as a one-pager. Showcases professional experience, selected projects, services, awards, recommendations, and contact information.

## Technology Stack
- **Jekyll**: Static site generator
- **Tailwind CSS v3**: Utility-first CSS framework (custom build)
- **Liquid**: Templating engine
- **GitHub Pages**: Hosting platform

## Color Palette - Flexoki
Using the Flexoki color system by Steph Ango for warm, accessible colors.

### Base Colors
- `fx-black`: #100F0F (primary dark)
- `fx-paper`: #FFFCF0 (primary light)
- `fx-base-950` to `fx-base-50`: Neutral grays (11 shades)

### Accent Colors
Each with 7 shades (50-700):
- `fx-red`, `fx-orange`, `fx-yellow`, `fx-green`
- `fx-cyan`, `fx-blue`, `fx-purple`, `fx-magenta`

### Theme Usage
- **Light theme**: `fx-paper` background, `fx-black` text
- **Dark theme**: `fx-black` background, `fx-paper` text

Configuration in `tailwind.config.js`.

## Project Structure

### Layouts
- `_layouts/onepager.html`: Main layout containing all structure

  - Gallery/list view toggle (in header)
  - Includes all sections

### Data Files (`_data/`)
Content separated from presentation:
- `hero.yml`: Hero section content (name, role, photo, description, location)
- `about.yml`: About section with intro, paragraphs, more_content (expandable), skills
- `experience.yml`: Work experience entries (6 featured positions)
- `services.yml`: Service offerings
- `awards.yml`: Awards and recognitions
- `recommendations.yml`: Client testimonials
- `contact.yml`: Contact information and links

Reusable components:
- `hero-section.html`: Top section with name, role, green dot status

- `services-section.html`: Services offered
- `awards-section.html`: Awards and recognitions

## Key Design Decisions

### Projects Section
- **Non-clickable cards**: Changed from `<a>` links to `<div>` to prevent navigation
- **Aspect ratio**: `aspect-[1632/1000]` matches exact thumbnail proportions
- **Grid layout**: 2 columns on desktop (`md:grid-cols-2`)
- **Slideshow button**: Black background (`fx-black`) with white text (`fx-paper`), inverts on hover
- **Spacing**: `mb-8` on grid container for separation from button

### Experience Section
- **Typography**:
  - Title: `text-xl`
  - Company: `text-lg`
  - Period: `text-sm` (de-emphasized)
  - Description: `text-lg`
- **Tags**: White background with black border (matches About section style)
- **Section title**: "Featured experience" (not complete work history)

### About Section
- **Expandable content**: "Read more" button shows `more_content` from YAML
- **Skills**: Prioritized order (strategy → design → technical → creative)

## Development Workflow

### Building CSS
```bash
npm run build:css
```
Compiles Tailwind CSS from `assets/css/tailwind.css` to `assets/css/output.css`.

### Local Development
```bash
bundle exec jekyll serve
```
Site runs at http://localhost:4000

### Git Workflow
- Branch: `website-2026`
- Main branch: `master`
- All commits include Claude co-authorship

## Content Guidelines

### Adding a Project
1. Create markdown file in `_posts/` with date format: `YYYY-MM-DD-title.md`
2. Set frontmatter:
   ```yaml
   ---
   layout: post
   title: Project Name
   date: YYYY-MM-DD HH:MM:SS -0300
   visible: true  # or false
   images: /assets/thumbs/filename.png
   tags:
     - Tag1
     - Tag2
   categories: todos consultorias
   description: Short description<br>Additional line
   ---
   ```
3. Add thumbnail to `assets/thumbs/` (1632x1000px recommended)
4. Adjust date to control display order in projects section

### Managing Visibility
- Set `visible: true` for projects to appear (max 6 shown)
- Set `visible: false` to hide from main page but keep in repository
- Only first 6 visible projects (sorted by date, newest first) are displayed

### Experience Entries
Structure in `_data/experience.yml`:
```yaml
- title: Job Title
  company: Company Name
  period: YYYY - Present (or YYYY - YYYY)
  description: Brief description of role and achievements
  tags:
    - Skill 1
    - Skill 2
```
